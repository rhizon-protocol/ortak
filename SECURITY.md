# Güvenlik Politikası

Ortak erken aşamadaki bir projedir; hassas veya kritik veriler için güvenlik sertifikalı bir ürün olarak kabul edilmemelidir.

Bir güvenlik açığını kamuya açık issue içinde kullanılabilir istismar adımlarıyla yayımlamayın. Depo yöneticisine GitHub profilindeki iletişim kanalından özel olarak ulaşın. Yanıtta dosya, kişisel veri, anahtar, token veya özel bağlantı paylaşmayın.

Öncelikli alanlar: istemci tarafı dosya erişimi, WebRTC eş onayı, aktarım bütünlüğü, XSS, servis çalışanı önbelleği ve bağımlılık/sürüm zinciri.
